# အလောင်းမင်းတရား — မုဆိုးဘို ၁၇၅၂ (Web Playtest)

[အခန်း ၁ ကို browser ဖြင့်ကစားရန်](https://luuzoe.github.io/moksobo-1752-web-test/?build=phone-r3)။ ဤသည် ဆက်လက်ပြင်ဆင်စမ်းသပ်နေသော prototype ဖြစ်ပြီး အပြီးသတ်ဂိမ်း သို့မဟုတ် Android app မဟုတ်ပါ။

## phone-r3 ပြင်ဆင်ချက်

ပေးထားသောဗီဒီယိုတွင် ဘယ်ဘက်မှရွေ့လျားမှုနှင့် ညာဘက်ကင်မရာဆွဲခြင်းကို တစ်ပြိုင်တည်းလုပ်သည့်အခါ ကင်မရာက ဇာတ်ကောင်အလွန်နီးကပ်သွားပြီး ကိုယ်ခန္ဓာကို ဖြတ်ဝင်မြင်ရသည်။ ကင်မရာလှည့်မှုကို ပတ်လမ်းအတိုင်း တဖြည်းဖြည်းလိုက်စေပြီး နံရံ/သစ်ပင်နားတွင် ကင်မရာ၏အရွယ်အစားကိုပါ စစ်ကာ ဇာတ်ကောင်ထံ အလွန်ကပ်မသွားစေရန် ပြင်ထားသည်။ နီးကပ်သောကင်မရာအကွာအဝေးနှင့် ဇာတ်ကောင်အပြည့်မြင်နိုင်မှုကို ထိန်းထားသည်။ ဗီဒီယိုထဲတွင် အခြားအတည်ပြုနိုင်သည့် Chapter 1 ချို့ယွင်းချက်ကို မတွေ့ပါ။

ခလုတ်နှစ်ဖက်၏ လက်ချောင်းပိုင်ဆိုင်မှုကို သီးခြားထိန်းထားဆဲဖြစ်ပြီး ကင်မရာလက်ချောင်းကိုလွှတ်သော်လည်း ရွေ့လျားမှုမပြတ်၊ ပြောင်းပြန်အစီအစဉ်ဖြင့်လွှတ်သည့်အခါလည်း ကင်မရာထိန်းချုပ်မှုမပြတ်ပါ။ ခလုတ်များကို ထောင့်များမှအတွင်းသို့ ရွှေ့ထားပြီး စကားပြောကတ်ကို ကျစ်လျစ်စေကာ စာရှည်ကို ဆွဲဖတ်နိုင်သည်။ ဂိမ်းသည် အလျားလိုက်မျက်နှာပြင်ဖြင့် ကစားရန် ဦးစားပေးထားသည်။

## စမ်းသပ်မှုရလဒ်

Chapter 1 source regression စမ်းသပ်မှု ၉ ခုနှင့် ဖုန်း UI စံချိန်စစ်ဆေးမှု ၁ ခုအားလုံး အောင်မြင်ခဲ့သည်။ Browser ထဲတွင် 844×390 DPR1 နှင့် 780×351 DPR2 အလျားလိုက်အရွယ်အစားများ၌ လက်နှစ်ချောင်းအသုံးပြုခြင်း၊ ကင်မရာလှည့်နေစဉ်ရွေ့ခြင်း၊ လက်လွှတ်အစီအစဉ်နှစ်မျိုးနှင့် portrait အနေအထားသို့လှည့်ခြင်းတို့ကို စမ်းသပ်ခဲ့ပြီး JavaScript error သို့မဟုတ် မအောင်မြင်သည့် asset request မရှိပါ။ တကယ့်ဖုန်းစက်ပေါ်တွင် မစမ်းသပ်ရသေးသောကြောင့် အပြီးအတိုင်အတည်ပြုထားသည်ဟု မဆိုလိုပါ။

## ကစားနည်း

ဖုန်းကို အလျားလိုက်ထားပြီး ဘယ်ဘက် joystick ဖြင့်ရွေ့ပါ။ ညာဘက်လွတ်နေရာကို ဆွဲ၍ ကင်မရာလှည့်ပါ။ ကွန်ပျူတာတွင် `WASD` သို့မဟုတ် မြှားခလုတ်များဖြင့်လျှောက်ပါ၊ `Shift` ကိုဖိ၍ပြေးပါ၊ `E`/`Space` ဖြင့်လုပ်ဆောင်ပါ သို့မဟုတ် စကားဆက်ပါ၊ `Q` ဖြင့်ရှောင်ပါ၊ `B` ဖြင့်ကာကွယ်ပါ၊ `V` ဖြင့်လက်နက်ပြောင်းပါ။

## သမိုင်းနှင့်အခန်းအကျယ်အဝန်း

ဂိမ်းသည် အခန်း ၁ — ၁၇၅၂ ခုနှစ် မုဆိုးဘိုမှ ခုခံရေးကို အောင်ဇေယျ စုစည်းသည့်အပိုင်း — ကိုသာ ဖုံးလွှမ်းသည်။ အမည်မဖော်ထားသော စာပို့သူ၊ စကားဝိုင်း၊ ပစ္စည်းစုဆောင်းမှု၊ မစ်ရှင်အစီအစဉ်နှင့် ရွာပုံစံတို့သည် gameplay အတွက် ဖန်တီးထားသော ပြန်လည်တည်ဆောက်မှုဖြစ်ပြီး မှတ်တမ်းတင်ထားသော ကိုယ်ရေးဖြစ်ရပ်များဟု မဆိုလိုပါ။ မူရင်း Godot project နှင့် Android package ကို ဤ Web preview တွင် မထည့်ထားပါ။

## ပထမဆုံးဖွင့်ချိန်

WebAssembly (`.wasm`) ဖိုင်သည် 39.5 MB ခန့်၊ game data (`.pck`) ဖိုင်သည် 60 MB ခန့်ရှိသည်။ ပထမဆုံးဖွင့်ချိန်သည် ဖုန်းနှင့်ကွန်ရက်အမြန်နှုန်းပေါ်မူတည်၍ ကြာနိုင်သည်။ WebAssembly နှင့် WebGL 2 ကို ပံ့ပိုးသော ခေတ်မီ browser ကို အသုံးပြုပါ။

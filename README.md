# အလောင်းမင်းတရား — မုဆိုးဘို (Web prototype · phone-r10)

[ဖုန်းအလျားလိုက် Web preview ကိုဖွင့်ရန်](https://luuzoe.github.io/moksobo-1752-web-test/?build=phone-r10) · [phone-r10 စာမျက်နှာ](https://luuzoe.github.io/moksobo-1752-web-test/phone-r10.html)

ဤသည် ဆက်လက်စမ်းသပ်နေသော prototype ဖြစ်သည်။ ယခုကစားနိုင်သည့်အကြောင်းအရာမှာ အခန်း ၁ တစ်ခန်းသာဖြစ်ပြီး Android app မဟုတ်ပါ။ ဖုန်းကို အလျားလိုက်ထား၍ ကစားရန် ဒီဇိုင်းလုပ်ထားသည်။

## phone-r10 ပြင်ဆင်ချက်များ

- Web ဂိမ်းဒေတာ `.pck` သည် ၃၃.၀ MB ခန့်၊ WebAssembly `.wasm` သည် ၃၉.၅ MB ခန့်ဖြစ်သည်။ ဖွင့်ချိန်သည် ဖုန်းနှင့် ကွန်ရက်ပေါ်မူတည်မည်။
- Landscape ဖုန်းမျက်နှာပြင်တွင် joystick ကို ပိုမြင်သာအောင် ချဲ့ထားသည် (၈၄၄×၃၉၀ စမ်းသပ်မျက်နှာပြင်၌ မြင်ရသောစက်ဝိုင်းအချင်း ၁၂၀ မှ ၁၃၆ px ခန့်)။ ကင်မရာ short-drag တုံ့ပြန်မှုကို ၂၅% ခန့်မြှင့်ပြီး frame-rate guard နှင့် physics interpolation ထည့်ထားသည်။ တစ်ပြိုင်နက် joystick/camera drag နှင့် လက်ချောင်းတစ်ဖက်စီ လွှတ်ခြင်းကိုလည်း regression test ဖြင့် စစ်ထားသည်။
- အိမ်အရေအတွက်ကို ၇ လုံးမှ ၁၅ လုံး၊ ရွာသားကို ၄ ယောက်မှ ၁၂ ယောက်အထိ တိုးပြီး လမ်းကြောင်း ၁၅ ခု၊ အိမ်ဝင်း ၇ ခု၊ ခွေး ၂ ကောင်၊ ကြက် ၈ ကောင်၊ ဝက် ၂ ကောင်နှင့် ငှက်အုပ်ငယ်တစ်အုပ် ထည့်ထားသည်။ အရေအတွက်၊ နေရာချထားမှုနှင့် တွေ့ဆုံမှုများသည် သမိုင်းမှတ်တမ်းအဖြစ် အတည်ပြုထားခြင်းမဟုတ်ဘဲ gameplay အတွက် ပြန်လည်တည်ဆောက်ထားခြင်းဖြစ်ကြောင်း ဂိမ်း၏သမိုင်းမှတ်ချက်တွင် ဖော်ပြထားသည်။
- လမ်းလျှောက်နေစဉ် ကမ္ဘာနှင့် ကင်မရာ update များကို physics interpolation ဖြင့် render frame များနှင့် ညှိထားသည်။ Stylized/low-poly ပုံစံ၊ ၆၅% 3D render scale နှင့် မြန်မာ HUD ကို ထိန်းထားသည်။

## အခန်း ၁ — အသက် ၁၈–၂၅ ဝန်းကျင်၊ ၁၇၃၂–၁၇၃၉

အခန်း ၁ ကို အစမှအဆုံး ကစားနိုင်သော လမ်းကြောင်းအဖြစ် ပြင်ထားသည်။ ၁၇၃၂ ဝန်းကျင်တွင် မုဆိုးဘို၌ ဒေသခံအရာရှိ/ရွာသူကြီးအဖြစ် နေထိုင်ခဲ့သည်ဆိုသော အဆို၊ ၁၇၃၃ ဟု EBSCO ရက်စွဲတပ်ထားသော ဇာတ်ကြောင်း၊ ၁၇၃၇ ဟု Gale ရက်စွဲတပ်ထားသော အခြားအဆို၊ ထို့နောက် မှတ်တမ်းနည်းပါးသောနှစ်များကို ဂိမ်းထဲတွင် ခွဲခြားဖော်ပြထားသည်။ Britannica/EBSCO က မွေးနှစ်ကို ၁၇၁၄ ဝန်းကျင်၊ Gale က ၁၇၁၅ ဟု ဖော်ပြသဖြင့် အသက် ၁၈ နှင့် ၂၅ သည် ခန့်မှန်းချက်သာဖြစ်သည်။ EBSCO ၏ ၁၇၃၃ အဆိုနှင့် Gale ၏ ၁၇၃၇ အဆိုကို အတည်ပြုထားသောဖြစ်ရပ်တစ်ခုတည်းအဖြစ် မပေါင်းစပ်ပါ။

၁၇၃၄–၁၇၃၉ တစ်နှစ်ချင်း ကိုယ်ရေးမှတ်တမ်းမလုံလောက်ပါ။ သစ်/ရိက္ခာ/ကိရိယာစုဆောင်းခြင်း၊ ရွာအစည်းအဝေး၊ ကင်းနေရာပြင်ဆင်ခြင်း၊ NPC များနှင့် စကားဝိုင်းများအပါအဝင် ၁၇၃၈–၁၇၃၉ ကစားပုံသည် ဂိမ်းအတွက် ပြန်လည်တည်ဆောက်မှုဖြစ်ပြီး အောင်ဇေယျ၏ အတည်ပြုထားသော ကိုယ်ရေးဖြစ်ရပ်များ မဟုတ်ပါ။ အခန်းအဆုံးတွင် ၁၇၃၉ ဝန်းကျင်/အသက် ၂၅ ဝန်းကျင်ဟု အမှတ်အသားတပ်ထားသည်။ အရင်းအမြစ်များနှင့် ခွဲခြားချက်အပြည့်အစုံကို [အခန်း ၁–၁၀ အချိန်စဉ်နှင့် မှတ်တမ်း](CHAPTER_PLAN_10.md) တွင်ကြည့်ပါ။

## စမ်းသပ်မှုရလဒ်နှင့် ကန့်သတ်ချက်

R10 အတွက် camera, movement/control, collision/grounding, character animation, village reconstruction နှင့် render audit စမ်းသပ်ချက် ၆ ခုလုံး အောင်မြင်သည်။ ၈၄၄×၃၉၀ Chromium touch emulation တွင် Web build ကိုဖွင့်ပြီး joystick လမ်းလျှောက်ခြင်းနှင့် camera drag လုပ်ရာ HTTP/JavaScript/console error မတွေ့ပါ။ Cloud Chromium သုံးသော SwiftShader software renderer ၏ အတို၊ မတည်ငြိမ်နိုင်သော frame sample တွင် R9 သည် ၃.၄ FPS ခန့်၊ R10 သည် ၂.၅–၂.၈ FPS ခန့် ရခဲ့သည်။ ဤကိန်းများသည် software-renderer စမ်းသပ်မှုသာဖြစ်ပြီး ဖုန်းစွမ်းဆောင်ရည် မဟုတ်ပါ။ R10 အပြည့်အစုံ အခန်း ၁ လမ်းကြောင်းကို ထပ်မစမ်းရသေးပါ။ ရုပ်ပိုင်းဖုန်းပေါ် FPS၊ တကယ့် touch၊ အပူ၊ ဘက်ထရီနှင့် မိုဘိုင်းကွန်ရက်ကို မစမ်းသပ်ရသေးသလို APK/AAB ကိုလည်း မထုတ်ထားပါ။

## ထိန်းချုပ်မှု

ဖုန်းတွင် ဘယ်ဘက် joystick ဖြင့်ရွေ့ပြီး ညာဘက်လွတ်နေရာကို ဆွဲ၍ ကင်မရာလှည့်ပါ။ အခြေအနေအလိုက် ညာဘက်စက်ဝိုင်းခလုတ်များ ပေါ်လာမည်။ ကွန်ပျူတာတွင် `WASD`/မြှားခလုတ်များဖြင့်ရွေ့၊ `Shift` ဖြင့်ပြေး၊ `E`/`Space` ဖြင့်လုပ်ဆောင်ပါ။

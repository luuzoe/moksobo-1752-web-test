# အလောင်းမင်းတရား — မုဆိုးဘို ၁၇၅၂ (Web Playtest)

ဤ repo သည် GitHub Pages တွင် တင်ထားသော Godot Web export ဖြစ်သည်။ [ဂိမ်းကိုဖွင့်ကစားရန်](./)။ ဤသည် prototype အဆင့် playtest ဖြစ်ပြီး အပြီးသတ် game သို့မဟုတ် native Android app မဟုတ်ပါ။

ဤ Web မူကြမ်းကို လက်ခံအတည်ပြုပြီးသော build ဟု မသတ်မှတ်ရသေးပါ။ အခန်း ၁ ကိုသာ ပြင်ဆင်စမ်းသပ်နေပြီး app ZIP မပြင်ဆင်ထားပါ။

## ဖုန်းထိန်းချုပ်မှု ပြင်ဆင်ချက်

ဘယ်ဘက်ရွေ့လျားမှုနှင့် ညာဘက်ကင်မရာအတွက် လက်ချောင်းတစ်ချောင်းစီကို သီးခြားဖမ်းယူပြီး တစ်ဖက်လွှတ်လျှင် ကျန်တစ်ဖက် မပျက်အောင် ပြင်ထားသည်။ ဖုန်းရုပ်ထွက်အချိုးနှင့် ကိုက်ညီသော ခလုတ်အရွယ်ကို သုံးထားပြီး ခလုတ်များကို ပိုကြီးစေကာ ထောင့်များမှ အတွင်းသို့ ရွှေ့ထားသည်။ စကားပြောကတ်ကို ကျစ်လျစ်စေပြီး စာရှည်ကို ကတ်အတွင်းဆွဲဖတ်နိုင်သည်။ နောက်လိုက်ကင်မရာကိုလည်း နီးစေထားသည်။

ဖုန်းအလျားလိုက် browser ပုံစံနှစ်မျိုးတွင် လက်နှစ်ချောင်းကို စတင်/လွှတ်သည့် အစီအစဉ်နှစ်မျိုး၊ ကင်မရာဆွဲခြင်းနှင့် မျက်နှာပြင်လှည့်ခြင်းတို့ကို စမ်းသပ်ထားသည်။ ဤသည် တကယ့်ဖုန်းပေါ်က စမ်းသပ်မှုမဟုတ်သေးပါ။ မူလဖုန်းတွင်ဖော်ပြခဲ့သည့် error အတိအကျကို ပြန်မတွေ့ရသေးသဖြင့် ဖုန်းတိုင်းတွင် အပြီးပျောက်ပြီဟု မသတ်မှတ်ထားပါ။

## ကစားနည်း

- **ဖုန်း/ထိတွေ့မျက်နှာပြင်:** landscape အနေအထားဖြင့်ကစားရန် အကြံပြုသည်။ Portrait ဖြင့်ဖွင့်လျှင် game က landscape mode ကို ကြိုးစားဖွင့်ပေးပြီး မရပါက ဖုန်းကို ကိုယ်တိုင်လှည့်ရန် ပြသမည်။ Browser အချို့တွင် lock သုံးရန် fullscreen ခလုတ်ကို နှိပ်ရနိုင်သည်။ Landscape ဖြစ်သွားလျှင် ဘယ်ဘက် joystick ဖြင့်ရွေ့ပြီး ညာဘက်ရှိ contextual ခလုတ်များကို သုံးပါ။
- **ကင်မရာ:** ဖုန်းတွင် ညာဘက်လွတ်နေရာကို ဆွဲပါ။ ကွန်ပျူတာတွင် ညာ mouse ခလုတ်ကို ဖိဆွဲပါ။ ရွေ့လျားမှုသည် လက်ရှိကင်မရာမြင်ကွင်းနှင့် လိုက်ညီသည်။
- **ကွန်ပျူတာ:** `WASD` သို့မဟုတ် မြှားခလုတ်များဖြင့် လျှောက်ပါ။ `Shift` / ပြေးခလုတ်ကို ဖိမှ ပြေးမည်။ `E`/`Space` လုပ်ဆောင် / စာမျက်နှာဆက်၊ `Q` ရှောင်၊ `B` ကာကွယ်၊ `V` လက်နက်ပြောင်းပါ။
- Mission အဆင့်တိုးတိုင်း progress ကို အလိုအလျောက် သိမ်းသည်။ လေ့ကျင့်တိုက်ခိုက်မှုကို ကိုယ်တိုင် မစတင်လျှင် ပြင်ဆင်ရေးမစ်ရှင်ကို အနှောင့်အယှက်မပေးပါ။

## ပထမဆုံးဖွင့်ချိန်

WebAssembly (`.wasm`) ဖိုင်သည် 39.5 MB ခန့်၊ game data (`.pck`) ဖိုင်သည် 60 MB ခန့်ရှိသည်။ ဖုန်းနှင့်ကွန်ရက်အမြန်နှုန်းပေါ်မူတည်၍ ပထမဆုံးဖွင့်ချိန်တွင် ဒေါင်းလုဒ်နှင့် စတင်တင်ရန် အချိန်ယူနိုင်သည်။ WebAssembly နှင့် WebGL 2 ကို ပံ့ပိုးသော ခေတ်မီ browser ကို အသုံးပြုပါ။

## Public build မှတ်ချက်

ဤ public repo တွင် browser ဖြင့်ကစားရန် လိုအပ်သော Godot Web export ဖိုင်များသာပါဝင်သည်။ Web export ထဲရှိ game data နှင့် browser JavaScript/WASM ဖိုင်များကို download လုပ်ကြည့်ရှုနိုင်သည်။ မူရင်း Godot editor project folder နှင့် native app package ကို ဤ repo တွင် မထည့်ထားပါ။

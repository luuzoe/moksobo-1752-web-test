# အလောင်းမင်းတရား — မုဆိုးဘို (Web prototype · phone-r15)

[ဖုန်းအလျားလိုက် Web preview ကိုဖွင့်ရန်](https://luuzoe.github.io/moksobo-1752-web-test/?build=phone-r15) · [phone-r15 Web export](https://luuzoe.github.io/moksobo-1752-web-test/phone-r15.html)

ဤသည် ဆက်လက်တည်ဆောက်နေသော Web prototype ဖြစ်သည်။ ယခုကစားနိုင်သည်မှာ အခန်း ၁ တစ်ခန်းသာဖြစ်ပြီး Android app မဟုတ်ပါ။ ဖုန်းကို အလျားလိုက်ထား၍ ကစားရန် ဦးစားပေးဒီဇိုင်းလုပ်ထားသည်။

## အခန်း ၁ — ၁၇၃၂–၁၇၃၉၊ အသက် ၁၈–၂၅ ဝန်းကျင်

အခန်း ၁ တွင် အစမှအဆုံးကစားနိုင်သော မစ်ရှင် ၈ ခုရှိသည်။ မွေးနှစ်ကို Britannica/EBSCO က ၁၇၁၄ ဝန်းကျင်၊ Gale က ၁၇၁၅ ဟု မတူညီစွာဖော်ပြသောကြောင့် အသက်နှင့် ကာလများသည် ခန့်မှန်းချက်သာဖြစ်သည်။

| မစ်ရှင် | အကြောင်းအရာ |
|---|---|
| ၁ | ၁၇၃၂ ဝန်းကျင်က ဒေသခံရာထူးအကြောင်း |
| ၂–၃ | EBSCO ၏ ၁၇၃၃ အဆိုကတ်များနှင့် ထိုအဆို၏ အဆုံးပိုင်း |
| ၄ | မှတ်တမ်းကွက်လပ်ကို သရုပ်ဖော်သည့် သစ်၊ ရိက္ခာ၊ ကိရိယာ စုဆောင်းမှု — ပြန်လည်တည်ဆောက်မှု |
| ၅–၆ | Gale ၏ ၁၇၃၇ အဆို — ဖမ်းဆီးခံရမှု၊ ငြင်းဆိုမှု၊ ပြန်လည်လွတ်မြောက်မှုနှင့် ရွာသားများကြား တိတ်ဆိတ်သောနှစ်များ |
| ၇ | ၁၇၃၈–၁၇၃၉ ရွာလုပ်ငန်းများ — ပြန်လည်တည်ဆောက်မှု |
| ၈ | ၁၇၃၉ ဝန်းကျင်/အသက် ၂၅ ဝန်းကျင် အဆုံးသတ်နှင့် အဆိုနှစ်ခုကို နှိုင်းယှဉ်ခြင်း |

**သမိုင်းသတိပြုရန်။** EBSCO ၏ ၁၇၃၃ အဆိုနှင့် Gale ၏ ၁၇၃၇ အဆိုကို အတည်ပြုထားသော အဖြစ်အပျက်တစ်ခုအဖြစ် မပေါင်းစပ်ထားပါ။ နှစ်ခုစလုံးကို သက်ဆိုင်ရာရင်းမြစ်၏ အဆိုအဖြစ် သီးခြားဖော်ပြထားသည်။ ၁၇၃၄–၁၇၃၉ တစ်နှစ်ချင်း ကိုယ်ရေးမှတ်တမ်းမလုံလောက်သဖြင့် စုဆောင်းမှု၊ ပြုပြင်မှု၊ NPC စကားဝိုင်းနှင့် မစ်ရှင်လုပ်ငန်းများကို ဂိမ်းအတွက် **ပြန်လည်တည်ဆောက်မှု** ဟု အမှတ်အသားတပ်ထားသည်။

## R15 — ဖုန်းဗီဒီယိုအထောက်အထားအပေါ် အခြေခံပြင်ဆင်မှု

**R14 ကို ပိုင်ရှင်က မအောင်မြင်ဟု အတည်ပြုထားသည်။** အရင် cloud စမ်းသပ်ချက်များ အောင်မြင်ခဲ့ခြင်းက ဖုန်းပေါ်က ရလဒ်ကို မပယ်ဖျက်နိုင်ပါ။ R15 သည် ပိုင်ရှင်ဖုန်းဖြင့် ပြန်စမ်းရန် candidate သာဖြစ်သည်။

Joystick အမိန့်ကို render frame ထပ်မစောင့်ဘဲ physics သို့ပို့ပြီး တကယ့်လှုပ်ရှားမှုအရှိန်တက်/ကျကို player controller တွင် ထိန်းသည်။ နှေးသော frame တွင် ကင်မရာဆွဲသည့် အကွာအဝေး ပျောက်မသွားစေရန် ပြင်ထားသည်။ ဖုန်း HUD တွင် မစ်ရှင်နံပါတ်၊ စုဆောင်းပြီးအရေအတွက်နှင့် နောက်လုပ်ရမည့်အမှတ်အသား၏ အမည်/အကွာအဝေး/ဦးတည်ရာကို ပြသည်။

အိမ်နှင့် လှေကားပလက်ဖောင်း collision ကို မြင်ရသော model အရွယ်နှင့် ညှိပြီး၊ အမိုးများအတွက် ကင်မရာကာကွယ်မှု၊ NPC နှင့် ဈေးစားပွဲတို့အတွက် တိုက်မိမှု ထည့်ထားသည်။

ဂိမ်းအတွက် ဖန်တီးထားသော ရေချောင်းကို ၇.၁ မီတာခန့်မှ ၂.၆ မီတာခန့်သို့ ကျဉ်းပြီး ရွာအရှေ့အစွန်းသို့ ရွှေ့ထားသည်။ အိမ် ၁၉ လုံးနှင့် မစ်ရှင်နေရာအားလုံး ရေပြင်မှ လွတ်သည်။ တံတား၊ ချဉ်းကပ်လမ်း၊ ရေကူးပုံစံနှင့် ရေမျက်နှာပြင်အမြင့်တို့ကိုလည်း ကိုက်ညီအောင် ညှိထားသည်။ **ဤအကျယ်နှင့် နေရာသည် သမိုင်းမှတ်တမ်းအရ အတည်ပြုထားခြင်း မဟုတ်ပါ။**

## ဖုန်းထိန်းချုပ်မှုနှင့် ရွာမြင်ကွင်း

ယခု build တွင် ပိုင်ရှင်ပေးထားသော ခလုတ်အရွယ်ကို ဦးစားပေး၍ ဘယ်ဘက် joystick ကို သေးပြီး အစွန်းမှ ခွာထားသည်။ Short-landscape တွင် ထိတွေ့ဧရိယာ 144 CSS px၊ မြင်ရသောစက်ဝိုင်း 132.48 CSS px နှင့် ညာဘက်လုပ်ဆောင်ချက်ခလုတ်များ 56 CSS px ဖြစ်သည်။ အပေါ်တန်းအကျယ်တစ်ခုလုံးကို ဖုံးသောနောက်ခံကို ဖယ်ပြီး ခေါင်းစဉ်နှင့် ရည်မှန်းချက်ကို ကျစ်လျစ်ထားသည်။ ကင်မရာတွင် interpolation နှစ်ခါထပ်သက်ရောက်မှုနှင့် position-lag pitch bob မဖြစ်စေရန် ပြင်ထားပြီး၊ frame နှေးသွားသော်လည်း touch တစ်ချက်မှ ကင်မရာအများကြီး လည်မသွားစေရန် ကန့်သတ်ထားသည်။

ရွာမြေပုံတွင် အိမ် ၁၉ လုံး၊ ရွာသား ၁၆ ဦး၊ တိရစ္ဆာန် ၁၂ ကောင်နှင့် ငှက်အုပ်၊ အိမ်ဝင်း/တဲ/ဈေး/ရေတွင်း/ထိုင်ခုံ၊ ရေချောင်းနှင့် တံတားတို့ပါဝင်သည်။ **ဤအရေအတွက်၊ လူဦးရေ၊ အိမ်ပုံစံနှင့် နေရာချထားမှု၊ တိရစ္ဆာန်နှင့် ရေချောင်း/တံတားတို့သည် သမိုင်းမှတ်တမ်းမဟုတ်ဘဲ gameplay အတွက် ပြန်လည်တည်ဆောက်ထားခြင်းသာဖြစ်သည်။** ဂိမ်းထဲက သမိုင်းမှတ်ချက်တွင်လည်း ထိုကန့်သတ်ချက်ကို ဖော်ပြထားသည်။

## Build နှင့် စမ်းသပ်မှု

`phone-r15.pck` သည် 33.06 MB၊ WebAssembly သည် 39.51 MB ခန့်ဖြစ်သည်။ ပထမဆုံးဖွင့်ချိန်သည် ကွန်ရက်နှင့် ဖုန်းပေါ်မူတည်၍ အချိန်ယူနိုင်သည်။ Loader သည် အမှန်တကယ်တင်ဆောင်မှုအခြေအနေကို ပြသည်။

- သီးခြား user-data ဧရိယာဖြင့် source regression 18 ခုလုံး အောင်မြင်သည်။ Capsule collision၊ အိမ်/NPC/စားပွဲ၊ မစ်ရှင်ရောက်နိုင်မှု၊ ရေကူးနှင့် တံတားဖြတ်လျှောက်မှုတို့ ပါဝင်သည်။
- Cloud Web 844×390 CSS px တွင် menu မှ ဝင်၍ ပထမမစ်ရှင်ကို ကိုယ်တိုင်ကစားပြီး၊ ကျန်မစ်ရှင်များကို joystick TouchEvent နှင့် UI MouseEvent input များဖြင့် မစ်ရှင် ၈/၈ အဆုံးသတ်အထိ စမ်းထားသည်။ Teleport၊ မစ်ရှင်ကျော်ခြင်း သို့မဟုတ် engine state setter မသုံးထားပါ။
- သီးခြားလက်နှစ်ချောင်းဖြင့် ရွေ့ရင်း ကင်မရာလှည့်မှုနှင့် လွှတ်လျှင် ရပ်ခြင်းကို စမ်းထားသည်။ Production pack ထဲတွင် QA telemetry/driver မပါဝင်ပါ။

**ဖုန်းအစစ်စမ်းသပ်မှု စောင့်ဆိုင်းဆဲ။** ဤရလဒ်များသည် cloud browser နှင့် Godot headless စမ်းသပ်ချက်များသာဖြစ်ပြီး ဖုန်းအစစ် FPS၊ ထိတွေ့တုံ့ပြန်မှု သို့မဟုတ် ချောမွေ့မှုကို အတည်မပြုပါ။ ပိုင်ရှင်က Web build ကို လက်ခံမှသာ APK/native အဆင့် ဆက်လုပ်မည်။ ယခု APK/AAB မထုတ်ထားပါ။

## ထိန်းချုပ်မှု

ဖုန်းတွင် ဘယ်ဘက် joystick ဖြင့် ရွေ့ပါ; ညာဘက်လွတ်နေရာကို ဆွဲ၍ ကင်မရာလှည့်ပါ။ အခြေအနေအလိုက် လုပ်ဆောင်ချက်ခလုတ်များ ပေါ်လာမည်။ ကွန်ပျူတာတွင် `WASD`/မြှားခလုတ်များဖြင့် ရွေ့၊ `Shift` ဖြင့်ပြေး၊ `E`/`Space` ဖြင့် လုပ်ဆောင်ပါ။

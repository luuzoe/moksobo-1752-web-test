# အလောင်းမင်းတရား — မုဆိုးဘို (Web prototype · phone-r9)

[ဖုန်းအလျားလိုက် Web preview ကိုဖွင့်ရန်](https://luuzoe.github.io/moksobo-1752-web-test/?build=phone-r9) · [phone-r9 စာမျက်နှာ](https://luuzoe.github.io/moksobo-1752-web-test/phone-r9.html)

ဤသည် ဆက်လက်စမ်းသပ်နေသော prototype ဖြစ်သည်။ ယခုကစားနိုင်သည့်အကြောင်းအရာမှာ အခန်း ၁ တစ်ခန်းသာဖြစ်ပြီး Android app မဟုတ်ပါ။ ဖုန်းကို အလျားလိုက်ထား၍ ကစားရန် ဒီဇိုင်းလုပ်ထားသည်။

## phone-r9 ပြင်ဆင်ချက်များ

- Web ဂိမ်းဒေတာ `.pck` ကို phone-r8 ရှိ ၆၂.၉ MB မှ ၃၃.၀ MB ခန့်သို့ လျှော့ထားသည် (၄၇.၅% လျော့နည်း)။ WebAssembly `.wasm` သည် ၃၉.၅ MB ခန့်ဖြစ်နေသေးသဖြင့် အမှန်တကယ်ဖွင့်ချိန်သည် ဖုန်းနှင့် ကွန်ရက်ပေါ်မူတည်သည်။ Clean release ကို local Chromium စမ်းသပ်ရာတွင် canvas အသင့်ဖြစ်ချိန် ၃.၅၀ စက္ကန့် တိုင်းတာခဲ့သော်လည်း ၎င်းသည် ဖုန်း/မိုဘိုင်းကွန်ရက်အမြန်နှုန်းကို ကိုယ်စားမပြုပါ။
- မီနူး၏ မလိုအပ်သောရှည်လျားသည့်စာသားနှင့် အဝင်ပိတ်နေသော မီးခိုးရောင် dialog ကို ဖယ်ရှားပြီး အခန်း ၁–၁၀ ကို ဘေးတိုက်လျှောကြည့်နိုင်သော ကျစ်လျစ်သည့် timeline အဖြစ် ပြင်ထားသည်။ အခန်း ၁ သာ ကစားနိုင်သည်။ အခန်း ၁ အောင်မြင်စွာပြီးမှ အခန်း ၂ ကို တိုးတက်မှုအဖြစ်သာ ဖွင့်ပြမည်ဖြစ်သော်လည်း အခန်း ၂ ကို မတည်ဆောက်ရသေးပါ။
- ဖုန်းအလျားလိုက်မျက်နှာပြင်တွင် joystick ကို ပိုမြင်သာပြီး အနားစွန်းမှ ခွာထားသည်။ ကင်မရာလှည့် sensitivity ကို ၇၅% မြှင့်ပြီး frame-rate guard ထားသဖြင့် လက်ကြီးဆွဲသည့်တစ်ဖရိမ်အတွင်း ကင်မရာမခုန်စေပါ။ ဘယ်လက် joystick နှင့် ညာဘက် camera drag ကို တစ်ပြိုင်နက်သုံးနိုင်ပြီး လက်ချောင်းတစ်ဖက်ကို လွှတ်သည့်အခါ အခြား input ကို မပိတ်စေပါ။ ခြေထောက်မြေထဲဝင်မှုနှင့် အိမ်/လမ်းတိုက်မှုကိုလည်း ပြင်ထားသည်။
- လမ်းလျှောက်/ပြေး/လှည့် အကူးအပြောင်းများကို ပိုချောမွေ့စေထားသည်။ Web အတွက် model/texture များကို လျှော့ချပြီး 3D render scale ကို ၆၅% သုံးထားသည်။ HUD နှင့် မြန်မာစာကို မူလ resolution ဖြင့် ဆွဲထားသည်။ ပုံစံသည် stylized/low-poly ဖြစ်နေသေးပြီး photorealistic မဟုတ်ပါ။

## အခန်း ၁ — အသက် ၁၈–၂၅ ဝန်းကျင်၊ ၁၇၃၂–၁၇၃၉

အခန်း ၁ ကို အစမှအဆုံး ကစားနိုင်သော လမ်းကြောင်းအဖြစ် ပြင်ထားသည်။ ၁၇၃၂ ဝန်းကျင်တွင် မုဆိုးဘို၌ ဒေသခံအရာရှိ/ရွာသူကြီးအဖြစ် နေထိုင်ခဲ့သည်ဆိုသော အဆို၊ ၁၇၃၃ ဟု EBSCO ရက်စွဲတပ်ထားသော ဇာတ်ကြောင်း၊ ၁၇၃၇ ဟု Gale ရက်စွဲတပ်ထားသော အခြားအဆို၊ ထို့နောက် မှတ်တမ်းနည်းပါးသောနှစ်များကို ဂိမ်းထဲတွင် ခွဲခြားဖော်ပြထားသည်။ Britannica/EBSCO က မွေးနှစ်ကို ၁၇၁၄ ဝန်းကျင်၊ Gale က ၁၇၁၅ ဟု ဖော်ပြသဖြင့် အသက် ၁၈ နှင့် ၂၅ သည် ခန့်မှန်းချက်သာဖြစ်သည်။ EBSCO ၏ ၁၇၃၃ အဆိုနှင့် Gale ၏ ၁၇၃၇ အဆိုကို အတည်ပြုထားသောဖြစ်ရပ်တစ်ခုတည်းအဖြစ် မပေါင်းစပ်ပါ။

၁၇၃၄–၁၇၃၉ တစ်နှစ်ချင်း ကိုယ်ရေးမှတ်တမ်းမလုံလောက်ပါ။ သစ်/ရိက္ခာ/ကိရိယာစုဆောင်းခြင်း၊ ရွာအစည်းအဝေး၊ ကင်းနေရာပြင်ဆင်ခြင်း၊ NPC များနှင့် စကားဝိုင်းများအပါအဝင် ၁၇၃၈–၁၇၃၉ ကစားပုံသည် ဂိမ်းအတွက် ပြန်လည်တည်ဆောက်မှုဖြစ်ပြီး အောင်ဇေယျ၏ အတည်ပြုထားသော ကိုယ်ရေးဖြစ်ရပ်များ မဟုတ်ပါ။ အခန်းအဆုံးတွင် ၁၇၃၉ ဝန်းကျင်/အသက် ၂၅ ဝန်းကျင်ဟု အမှတ်အသားတပ်ထားသည်။ အရင်းအမြစ်များနှင့် ခွဲခြားချက်အပြည့်အစုံကို [အခန်း ၁–၁၀ အချိန်စဉ်နှင့် မှတ်တမ်း](CHAPTER_PLAN_10.md) တွင်ကြည့်ပါ။

## စမ်းသပ်မှုရလဒ်နှင့် ကန့်သတ်ချက်

Godot regression/smoke စမ်းသပ်မှု ၁၁ ခု အောင်မြင်ပြီး ၈၄၄×၃၉၀ touch-enabled Chromium browser emulation တွင် အခန်း ၁ အစမှအဆုံးကို ၃ မိနစ် ၃၉ စက္ကန့်ခန့်ဖြင့် ကစားကာ အခန်း ၂ တိုးတက်မှုဖွင့်ခြင်းကို စစ်ဆေးခဲ့သည်။ တစ်ပြိုင်နက် joystick/camera input၊ finger release order၊ menu scrolling၊ final completion နှင့် browser HTTP/JavaScript error မရှိမှုတို့ကို စစ်ဆေးထားသည်။ Chromium သည် SwiftShader software renderer သုံးသည်။ ရုပ်ပိုင်းဖုန်းပေါ် FPS၊ အပူ၊ ဘက်ထရီ၊ တကယ့် touch သို့မဟုတ် မိုဘိုင်းကွန်ရက်ကို မစမ်းသပ်ရသေးသဖြင့် ဤရလဒ်များသည် ဖုန်းစွမ်းဆောင်ရည်အာမခံချက် မဟုတ်ပါ။ APK/AAB ကိုလည်း မထုတ်ထားပါ။

## ထိန်းချုပ်မှု

ဖုန်းတွင် ဘယ်ဘက် joystick ဖြင့်ရွေ့ပြီး ညာဘက်လွတ်နေရာကို ဆွဲ၍ ကင်မရာလှည့်ပါ။ အခြေအနေအလိုက် ညာဘက်စက်ဝိုင်းခလုတ်များ ပေါ်လာမည်။ ကွန်ပျူတာတွင် `WASD`/မြှားခလုတ်များဖြင့်ရွေ့၊ `Shift` ဖြင့်ပြေး၊ `E`/`Space` ဖြင့်လုပ်ဆောင်ပါ။

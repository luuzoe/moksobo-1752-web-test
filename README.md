# အလောင်းမင်းတရား — မုဆိုးဘို (Web prototype · phone-r14)

[ဖုန်းအလျားလိုက် Web preview ကိုဖွင့်ရန်](https://luuzoe.github.io/moksobo-1752-web-test/?build=phone-r14) · [phone-r14 Web export](https://luuzoe.github.io/moksobo-1752-web-test/phone-r14.html)

ဤသည် ဆက်လက်တည်ဆောက်နေသော Web prototype ဖြစ်သည်။ ယခုကစားနိုင်သည်မှာ အခန်း ၁ တစ်ခန်းသာဖြစ်ပြီး Android app မဟုတ်ပါ။ ဖုန်းကို အလျားလိုက်ထား၍ ကစားရန် ဦးစားပေးဒီဇိုင်းလုပ်ထားသည်။

## အခန်း ၁ — ၁၇၃၂–၁၇၃၉၊ အသက် ၁၈–၂၅ ဝန်းကျင်

အခန်း ၁ တွင် အစမှအဆုံးကစားနိုင်သော မစ်ရှင် ၈ ခုရှိသည်။ မွေးနှစ်ကို Britannica/EBSCO က ၁၇၁၄ ဝန်းကျင်၊ Gale က ၁၇၁၅ ဟု မတူညီစွာဖော်ပြသောကြောင့် အသက်နှင့် ကာလများသည် ခန့်မှန်းချက်သာဖြစ်သည်။

| မစ်ရှင် | အကြောင်းအရာ |
|---|---|
| ၁ | ၁၇၃၂ ဝန်းကျင်က ဒေသခံရာထူးအကြောင်း |
| ၂–၃ | EBSCO ၏ ၁၇၃၃ အဆိုကတ်များနှင့် ထိုအဆို၏ အဆုံးပိုင်း |
| ၄ | မှတ်တမ်းကွက်လပ်ကို သရုပ်ဖော်သည့် သစ်၊ ရိက္ခာ၊ ကိရိယာ စုဆောင်းမှု — ပြန်လည်တည်ဆောက်မှု |
| ၅–၆ | Gale ၏ ၁၇၃၇ အဆို — ဖမ်းဆီးခံရမှု၊ ငြင်းဆိုမှု၊ ပြန်လည်လွတ်မြောက်မှုနှင့် ရွာသားများကြား တိတ်ဆိတ်သောနှစ်များ |
| ၇ | ၁၇၃၈–၁၇၃၉ ရွာလုပ်ငန်းများ — ပြန်လည်တည်ဆောက်မှု |
| ၈ | ၁၇၃၉ ဝန်းကျင်/အသက် ၂၅ ဝန်းကျင် အဆုံးသတ်နှင့် အဆိုနှစ်ခုကို နှိုင်းယှဉ်ခြင်း |

**သမိုင်းသတိပြုရန်။** EBSCO ၏ ၁၇၃၃ အဆိုနှင့် Gale ၏ ၁၇၃၇ အဆိုကို အတည်ပြုထားသော အဖြစ်အပျက်တစ်ခုအဖြစ် မပေါင်းစပ်ထားပါ။ နှစ်ခုစလုံးကို သက်ဆိုင်ရာရင်းမြစ်၏ အဆိုအဖြစ် သီးခြားဖော်ပြထားသည်။ ၁၇၃၄–၁၇၃၉ တစ်နှစ်ချင်း ကိုယ်ရေးမှတ်တမ်းမလုံလောက်သဖြင့် စုဆောင်းမှု၊ ပြုပြင်မှု၊ NPC စကားဝိုင်းနှင့် မစ်ရှင်လုပ်ငန်းများကို ဂိမ်းအတွက် **ပြန်လည်တည်ဆောက်မှု** ဟု အမှတ်အသားတပ်ထားသည်။

## R14 — runtime နှင့် grounding ပြင်ဆင်ချက်

ရွာစည်းရိုးတိုင် ၁၁၄ တိုင်ကို နံရံ/ပစ္စည်းအလိုက် MultiMesh ၁၂ အုပ်စု၊ တိရစ္ဆာန် rigid part ၅၂ ခုကို material အလိုက် ၃၀ အုပ်စုဖြင့် ဆွဲသည်။ မူလ stockade collision ၁၂၀ ခုနှင့် တိရစ္ဆာန် source triangle အားလုံးကို regression စစ်ထားသည်။

ကင်မရာက လုံခြုံပြီးသား လမ်းကြောင်းတိုကို ထပ်မံ collision စစ်နေမှုကို ဖယ်ထားသည်။ ဖုန်း Web တွင် မျက်နှာပြင်ပြင်ပရှိ ရွာသား rig များ၏ processing ကို ရပ်ပေးသော်လည်း ရွာလမ်းကြောင်း simulation ကို ဆက်လုပ်သည်။ ၂၈ မီတာထက်ဝေးသော သစ်ပင်၏ လေတိုက်လှုပ်ရှားမှု transform update များကိုလည်း ကျော်ထားသည်။ ဇာတ်ကောင်၏ ဖိနပ်အောက်ခြေ clearance ကို idle၊ လမ်းလျှောက်၊ ရေကူးမှကမ်းတက်ခြင်းနှင့် ပြန်ပေါ်ခြင်းအတွင်း မပျောက်စေရန် ပြင်ထားသည်။

Joystick နှင့် ညာဘက်ခလုတ်အရွယ်ကို မချဲ့ထားပါ။ R13/R14 ကို တူညီသော cloud software renderer တွင် အလှည့်ကျ နှိုင်းယှဉ်ထားသော်လည်း ထို timing ကို ဖုန်းအစစ် FPS ဟု မယူဆရပါ။ ပိုင်ရှင်တင်ပြထားသည့် ဖုန်းပေါ်က ပြဿနာအားလုံး ပြေလည်ကြောင်း အတည်မပြုရသေးပါ။

## ဖုန်းထိန်းချုပ်မှုနှင့် ရွာမြင်ကွင်း

R13 တွင် ပိုင်ရှင်ပေးထားသော ခလုတ်အရွယ်ကို ဦးစားပေး၍ ဘယ်ဘက် joystick ကို သေးပြီး အစွန်းမှ ခွာထားသည်။ Short-landscape တွင် ထိတွေ့ဧရိယာ 144 CSS px၊ မြင်ရသောစက်ဝိုင်း 132.48 CSS px နှင့် ညာဘက်လုပ်ဆောင်ချက်ခလုတ်များ 56 CSS px ဖြစ်သည်။ အပေါ်တန်းအကျယ်တစ်ခုလုံးကို ဖုံးသောနောက်ခံကို ဖယ်ပြီး ခေါင်းစဉ်နှင့် ရည်မှန်းချက်ကို ကျစ်လျစ်ထားသည်။ ကင်မရာတွင် interpolation နှစ်ခါထပ်သက်ရောက်မှုနှင့် position-lag pitch bob မဖြစ်စေရန် ပြင်ထားပြီး၊ frame နှေးသွားသော်လည်း touch တစ်ချက်မှ ကင်မရာအများကြီး လည်မသွားစေရန် ကန့်သတ်ထားသည်။

ရွာမြေပုံတွင် အိမ် ၁၉ လုံး၊ ရွာသား ၁၆ ဦး၊ တိရစ္ဆာန် ၁၂ ကောင်နှင့် ငှက်အုပ်၊ အိမ်ဝင်း/တဲ/ဈေး/ရေတွင်း/ထိုင်ခုံ၊ ရေချောင်းနှင့် တံတားတို့ပါဝင်သည်။ **ဤအရေအတွက်၊ လူဦးရေ၊ အိမ်ပုံစံနှင့် နေရာချထားမှု၊ တိရစ္ဆာန်နှင့် ရေချောင်း/တံတားတို့သည် သမိုင်းမှတ်တမ်းမဟုတ်ဘဲ gameplay အတွက် ပြန်လည်တည်ဆောက်ထားခြင်းသာဖြစ်သည်။** ဂိမ်းထဲက သမိုင်းမှတ်ချက်တွင်လည်း ထိုကန့်သတ်ချက်ကို ဖော်ပြထားသည်။

## Build နှင့် စမ်းသပ်မှု

`phone-r14.pck` သည် ၃၃.၀၅ MB ခန့်၊ WebAssembly `phone-r14.wasm` သည် ၃၉.၅၁ MB ခန့်ဖြစ်သည်။ ဤပမာဏများကြောင့် ပထမဆုံးဖွင့်ချိန်သည် ကွန်ရက်နှင့် ဖုန်းပေါ်မူတည်၍ အချိန်ယူနိုင်သည်။ Loader တွင် အမှန်တကယ်တင်ဆောင်မှုရာခိုင်နှုန်း၊ ကြာချိန်နှင့် update ကြာနေပါက သတိပေးချက်ကို ပြသည်; ပြီးဆုံးချိန်ကို ကြိုတင်ခန့်မှန်းမထားပါ။

- လက်ရှိ Godot source regression စမ်းသပ်မှု ၁၄ ခုလုံး အောင်မြင်သည်။ အခန်း ၁ အစမှအဆုံး၊ မြေပြင်တိုက်မိမှု၊ animation၊ save/မီနူးနှင့် touch controls ပါဝင်သည်။
- Chromium touch emulation 844×390 DPR1၊ 800×360 DPR1 နှင့် 844×390 DPR2 တို့တွင် joystick လမ်းလျှောက်/လွှတ်ရပ်မှု၊ လက်နှစ်ချောင်းဖြင့် ရွေ့ရင်းကင်မရာလှည့်မှု၊ Sprint နှင့် သီးခြားလုပ်ဆောင်ချက်ခလုတ်များကို real touch event များဖြင့် စစ်ထားသည်။
- QA-only build တွင် physics 20 Hz ဖြင့် ကင်မရာ follow offset/pitch နှင့် ဇာတ်ကောင်တစ်ကိုယ်လုံး screen အတွင်းရှိမှုကို တိုင်းတာထားသည်။ QA bridge ကို production export ထဲ မထည့်ထားပါ။
- Stockade/animal batching ကို source test ထပ်ထည့်ထားပြီး collision နှင့် source triangle မပြောင်းကြောင်း စစ်ထားသည်။ Mesh node budget ကို FPS အထောက်အထားဟု မသုံးထားပါ။

**ဖုန်းအစစ်စမ်းသပ်မှု စောင့်ဆိုင်းဆဲ။** အထက်ပါရလဒ်များသည် cloud Chromium/SwiftShader touch emulation နှင့် Godot headless စမ်းသပ်မှုများသာဖြစ်သည်။ ဖုန်းအစစ်၏ FPS သို့မဟုတ် လမ်းလျှောက်စဉ် တုန်မှုကင်းရှင်းမှုကို အတည်မပြုနိုင်သေးပါ။ ဤဗားရှင်းကို လက်ခံပြီးသော release မဟုတ်ဘဲ ပိုင်ရှင်ဖုန်းဖြင့် စမ်းရန် Web preview candidate အဖြစ်သာ ထုတ်ထားသည်။ Android APK/AAB မထုတ်ရသေးပါ။

## ထိန်းချုပ်မှု

ဖုန်းတွင် ဘယ်ဘက် joystick ဖြင့် ရွေ့ပါ; ညာဘက်လွတ်နေရာကို ဆွဲ၍ ကင်မရာလှည့်ပါ။ အခြေအနေအလိုက် လုပ်ဆောင်ချက်ခလုတ်များ ပေါ်လာမည်။ ကွန်ပျူတာတွင် `WASD`/မြှားခလုတ်များဖြင့် ရွေ့၊ `Shift` ဖြင့်ပြေး၊ `E`/`Space` ဖြင့် လုပ်ဆောင်ပါ။

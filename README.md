# အလောင်းမင်းတရား — မုဆိုးဘို ၁၇၅၂ (Web Playtest)

[အခန်း ၁ Web preview ကိုဖွင့်ရန်](https://luuzoe.github.io/moksobo-1752-web-test/?build=phone-r8)။ ဤသည် ဆက်လက်စမ်းသပ်နေသော prototype ဖြစ်ပြီး အပြီးသတ်ဂိမ်း သို့မဟုတ် Android app မဟုတ်ပါ။

## phone-r8 — မြင်ကွင်းနှင့် ဇာတ်ကောင်လှုပ်ရှားမှု

လက်ရှိ asset များကိုသာအသုံးပြုပြီး မိုးကောင်းကင်/အလင်းအရောင်၊ မြေမျက်နှာပြင် normal detail နှင့် shading ကို သဘာဝကျအောင် ညှိထားသည်။ ရွာရှိ သစ်ပင်မော်ဒယ်များကို လေတိုက်သလို အနည်းငယ်လှုပ်ရှားစေပြီး၊ အောင်ဇေယျဇာတ်ကောင်တွင် လမ်းလျှောက်/ပြေးချိန် ခန္ဓာကိုယ်အလေးချိန်ရွေ့မှုနှင့် လှည့်ကွေ့ချိန် အပျော့စား lean ထည့်ထားသည်။ Controls, mission flow, UI, save/progression နှင့် မူရင်းမီနူးပုံကို မပြောင်းထားပါ။ ပြင်ပ asset အသစ်မထည့်ထားပါ။ ဤသည် photorealism သို့မဟုတ် motion-capture အရည်အသွေး မဟုတ်ပါ။

## phone-r7 — အခန်း ၁ gameplay loop

အခန်း ၁ ကို အစမှအဆုံးအထိ ကစားနိုင်သော mission loop အဖြစ် တိုးချဲ့ထားသည် — သတင်းပို့သူ၏ briefing၊ ပစ္စည်း ၃ မျိုးစုဆောင်းခြင်း၊ ပြန်လည်တည်ဆောက်ထားသော အမိန့်အစည်းအဝေးနှင့် ဂိတ်/ကင်းနေရာ ၃ ခု ပြင်ဆင်ခြင်းတို့ ပါဝင်သည်။ အခန်း ၁ ပြီးဆုံးလျှင် အခန်း ၂ ကို တိုးတက်မှုအဖြစ် ဖွင့်ပေးသော်လည်း ကစားနိုင်သောအကြောင်းအရာ မတည်ဆောက်ရသေးဟု ရှင်းလင်းစွာပြထားသည်။ မီနူးတွင် အခန်း ၁–၁၀ timeline ပါရှိပြီး၊ ပြီးစီးမှုမတိုင်မီ အခန်း ၂–၁၀ လော့ခ်ထားသည်။ ပြီးစီးပြီးနောက် အခန်း ၂ သာ progress-unlocked ဖြစ်ပြီး မတည်ဆောက်ရသေးသည့်အခြေအနေကို ဆက်ပြထားကာ အခန်း ၃–၁၀ လော့ခ်ထားသည်။

Joystick နှင့် camera ကို တစ်ပြိုင်နက်အသုံးပြုရာ spin ဖြစ်ခြင်း၊ အိမ်တိုက်မှုနှင့် ခြေထောက်မြေထဲဝင်ခြင်း၊ မြန်မာစာ UI အရွယ်အစားနှင့် ပြတ်သားမှုတို့ကို ပြင်ဆင်ထားသည်။ သမိုင်းမှတ်တမ်းအခြေခံအချက်များနှင့် ဂိမ်းအတွက် ပြန်လည်တည်ဆောက်ထားသော dialogue/mission အသေးစိတ်များကို သီးခြားတံဆိပ်တပ်ထားသည်။

## phone-r6 — ထိန်းချုပ်မှုနှင့် landscape UI

Joystick ကိုဖိထားစဉ် player သည် camera ဦးတည်ချက်အသစ်ကို frame တိုင်းလိုက်မပြောင်းတော့ပါ။ လှုပ်ရှားမှုဦးတည်ချက်ကို ထိန်းထားပြီး လက်ချောင်းထိတွေ့မှု တစ်ခဏပြတ်သွားခြင်းကိုလည်း ၀.၁၂ စက္ကန့်အတွင်း ခံနိုင်အောင် ပြင်ထားသည်။ Camera swipe ကို frame တစ်ခုစီတွင် တစ်ကြိမ်သာယူပြီး turn rate ကိုကန့်သတ်ထားသည်။ အခန်း ၁ ပြီးဆုံးပြီးနောက် mission status ကိုတိုတောင်းစွာပြပြီး၊ landscape ဖုန်းတွင် mission card နှင့် joystick ပုံကိုလည်း လျှော့ထားသည်။ မီနူး၊ အသုံးပြုသူပေးထားသောရွာပုံ၊ save/continue၊ ညာဘက်ဝိုင်းပုံ action ခလုတ်များနှင့် တတိယပုဂ္ဂိုလ်မြင်ကွင်းကို ထိန်းသိမ်းထားသည်။

## စမ်းသပ်မှုရလဒ်

Godot source regression test ၁၁ ခုလုံး အောင်မြင်ခဲ့သည် — menu/save, gameplay controls/flow, animation, mobile controls, multitouch, camera, grounding/collision, responsive UI, Chapter 1 walkthrough နှင့် render workload ပါဝင်သည်။ ၈၄၄×၃၉၀ touch-enabled Chromium WebGL 2 browser emulation တွင် မီနူးမှ အဖွင့် dialogue ပြီး gameplay ထိ၊ simultaneous move/camera touch နှင့် portrait orientation notice တို့ကို စစ်ဆေးခဲ့ပြီး HTTP, JavaScript သို့မဟုတ် console error မတွေ့ပါ။ Render workload သည် mesh ၂၂၁ ခု / triangle ၃၇၈,၈၇၄ ခုဖြစ်ပြီး R7 ထက် geometry မတိုးပါ။ Browser သည် SwiftShader software renderer သုံးသောကြောင့် ထို frame-time ကို ဖုန်း GPU ၏ FPS ဟု မယူဆရပါ။ ရုပ်ပိုင်းဆိုင်ရာဖုန်းပေါ်တွင် performance/heat/touch မစမ်းသပ်ရသေးပါ။

## ကစားနည်း

ဖုန်းကို အလျားလိုက်ထားပြီး ဘယ်ဘက် joystick ဖြင့်ရွေ့ပါ။ ညာဘက်လွတ်နေရာကိုဆွဲ၍ camera လှည့်ပါ။ ကွန်ပျူတာတွင် `WASD` သို့မဟုတ် မြှားခလုတ်များဖြင့်လျှောက်ပါ၊ `Shift` ကိုဖိ၍ပြေးပါ၊ `E`/`Space` ဖြင့်လုပ်ဆောင်ပါ သို့မဟုတ် စကားဆက်ပါ၊ `Q` ဖြင့်ရှောင်ပါ၊ `B` ဖြင့်ကာကွယ်ပါ၊ `V` ဖြင့်လက်နက်ပြောင်းပါ။

## သမိုင်းနှင့် အခန်းအကျယ်အဝန်း

ဂိမ်းသည် အခန်း ၁ — ၁၇၅၂ ခုနှစ် မုဆိုးဘိုမှ ခုခံရေးကို အောင်ဇေယျ စုစည်းသည့်အပိုင်း — ကိုသာဖုံးလွှမ်းသည်။ အမည်မဖော်ထားသော စာပို့သူ၊ စကားဝိုင်း၊ ပစ္စည်းစုဆောင်းမှု၊ မစ်ရှင်အစီအစဉ်နှင့် ရွာပုံစံတို့သည် gameplay အတွက် ဖန်တီးထားသော ပြန်လည်တည်ဆောက်မှုဖြစ်ပြီး မှတ်တမ်းတင်ထားသော ကိုယ်ရေးဖြစ်ရပ်များဟု မဆိုလိုပါ။ အခန်း ၂–၁၀ ကို မတည်ဆောက်ရသေးပါ။ Android package ကို ဤ Web preview တွင် မထည့်ထားပါ။

## ပထမဆုံးဖွင့်ချိန်

WebAssembly (`.wasm`) ဖိုင်သည် ၃၉ MB ခန့်၊ game data (`.pck`) ဖိုင်သည် ၆၀ MB ခန့်ရှိသည်။ ပထမဆုံးဖွင့်ချိန်သည် ဖုန်းနှင့်ကွန်ရက်အမြန်နှုန်းပေါ်မူတည်၍ ကြာနိုင်သည်။ WebAssembly နှင့် WebGL 2 ကို ပံ့ပိုးသော ခေတ်မီ browser ကို အသုံးပြုပါ။

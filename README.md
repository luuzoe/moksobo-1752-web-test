# အလောင်းမင်းတရား — မုဆိုးဘို (Web prototype · phone-r12)

[ဖုန်းအလျားလိုက် Web preview ကိုဖွင့်ရန်](https://luuzoe.github.io/moksobo-1752-web-test/?build=phone-r12) · [phone-r12 Web export](https://luuzoe.github.io/moksobo-1752-web-test/phone-r12.html)

ဤသည် ဆက်လက်တည်ဆောက်နေသော Web prototype ဖြစ်သည်။ ယခုကစားနိုင်သည်မှာ အခန်း ၁ တစ်ခန်းသာဖြစ်ပြီး Android app မဟုတ်ပါ။ ဖုန်းကို အလျားလိုက်ထား၍ ကစားရန် ဦးစားပေးဒီဇိုင်းလုပ်ထားသည်။

## အခန်း ၁ — ၁၇၃၂–၁၇၃၉၊ အသက် ၁၈–၂၅ ဝန်းကျင်

အခန်း ၁ တွင် အစမှအဆုံးကစားနိုင်သော မစ်ရှင် ၈ ခုရှိသည်။ မွေးနှစ်ကို Britannica/EBSCO က ၁၇၁၄ ဝန်းကျင်၊ Gale က ၁၇၁၅ ဟု မတူညီစွာဖော်ပြသောကြောင့် အသက်နှင့် ကာလများသည် ခန့်မှန်းချက်သာဖြစ်သည်။

| မစ်ရှင် | အကြောင်းအရာ |
|---|---|
| ၁ | ၁၇၃၂ ဝန်းကျင်က ဒေသခံရာထူးအကြောင်း |
| ၂–၃ | EBSCO ၏ ၁၇၃၃ အဆိုကတ်များနှင့် ထိုအဆို၏ အဆုံးပိုင်း |
| ၄ | မှတ်တမ်းကွက်လပ်ကို သရုပ်ဖော်သည့် သစ်၊ ရိက္ခာ၊ ကိရိယာ စုဆောင်းမှု — ပြန်လည်တည်ဆောက်မှု |
| ၅–၆ | Gale ၏ ၁၇၃၇ အဆို — ဖမ်းဆီးခံရမှု၊ ငြင်းဆိုမှု၊ ပြန်လည်လွတ်မြောက်မှုနှင့် ရွာသားများကြား တိတ်ဆိတ်သောနှစ်များ |
| ၇ | ၁၇၃၈–၁၇၃၉ ရွာလုပ်ငန်းများ — ပြန်လည်တည်ဆောက်မှု |
| ၈ | ၁၇၃၉ ဝန်းကျင်/အသက် ၂၅ ဝန်းကျင် အဆုံးသတ်နှင့် အဆိုနှစ်ခုကို နှိုင်းယှဉ်ခြင်း |

**သမိုင်းသတိပြုရန်။** EBSCO ၏ ၁၇၃၃ အဆိုနှင့် Gale ၏ ၁၇၃၇ အဆိုကို အတည်ပြုထားသော အဖြစ်အပျက်တစ်ခုအဖြစ် မပေါင်းစပ်ထားပါ။ နှစ်ခုစလုံးကို သက်ဆိုင်ရာရင်းမြစ်၏ အဆိုအဖြစ် သီးခြားဖော်ပြထားသည်။ ၁၇၃၄–၁၇၃၉ တစ်နှစ်ချင်း ကိုယ်ရေးမှတ်တမ်းမလုံလောက်သဖြင့် စုဆောင်းမှု၊ ပြုပြင်မှု၊ NPC စကားဝိုင်းနှင့် မစ်ရှင်လုပ်ငန်းများကို ဂိမ်းအတွက် **ပြန်လည်တည်ဆောက်မှု** ဟု အမှတ်အသားတပ်ထားသည်။

## ဖုန်းထိန်းချုပ်မှုနှင့် ရွာမြင်ကွင်း

R12 တွင် ဘယ်ဘက် joystick ၏ မြင်ရသောစက်ဝိုင်းနှင့် ထိတွေ့ဧရိယာကို ချဲ့ထားပြီး landscape စခရင်အတွင်း လုံခြုံစွာထားသည်။ ညာဘက်လွတ်နေရာကို ဆွဲ၍ ကင်မရာလှည့်နိုင်ပြီး၊ လမ်းလျှောက်မှုကို ပိုချောမွေ့စေရန် physics interpolation နှင့် ကင်မရာတုံ့ပြန်မှုကို ထိန်းညှိထားသည်။

ရွာမြေပုံတွင် အိမ် ၁၉ လုံး၊ ရွာသား ၁၆ ဦး၊ တိရစ္ဆာန် ၁၂ ကောင်နှင့် ငှက်အုပ်၊ အိမ်ဝင်း/တဲ/ဈေး/ရေတွင်း/ထိုင်ခုံ၊ ရေချောင်းနှင့် တံတားတို့ပါဝင်သည်။ **ဤအရေအတွက်၊ လူဦးရေ၊ အိမ်ပုံစံနှင့် နေရာချထားမှု၊ တိရစ္ဆာန်နှင့် ရေချောင်း/တံတားတို့သည် သမိုင်းမှတ်တမ်းမဟုတ်ဘဲ gameplay အတွက် ပြန်လည်တည်ဆောက်ထားခြင်းသာဖြစ်သည်။** ဂိမ်းထဲက သမိုင်းမှတ်ချက်တွင်လည်း ထိုကန့်သတ်ချက်ကို ဖော်ပြထားသည်။

## Build နှင့် စမ်းသပ်မှု

`phone-r12.pck` သည် ၃၃.၀၅ MB ခန့်၊ WebAssembly `phone-r12.wasm` သည် ၃၉.၅၁ MB ခန့်ဖြစ်သည်။ ဤပမာဏများကြောင့် ပထမဆုံးဖွင့်ချိန်သည် ကွန်ရက်နှင့် ဖုန်းပေါ်မူတည်၍ အချိန်ယူနိုင်သည်။ Loader တွင် အမှန်တကယ်တင်ဆောင်မှုရာခိုင်နှုန်း၊ ကြာချိန်နှင့် update ကြာနေပါက သတိပေးချက်ကို ပြသည်; ပြီးဆုံးချိန်ကို ကြိုတင်ခန့်မှန်းမထားပါ။

- Godot source regression စမ်းသပ်မှု ၁၃ ခုလုံး အောင်မြင်သည်။
- QA-only Web build ဖြင့် မစ်ရှင် ၈ ခု၊ EBSCO/Gale အဆိုခွဲခြားမှု၊ mission flags၊ ပြီးဆုံးမှုနှင့် save/reload ကို စစ်သည့် browser check ၅၂ ခုလုံး အောင်မြင်ပြီး JavaScript/page/network error မရှိပါ။ QA စမ်းသပ်ရန်သာ ထည့်ထားသော bridge ကို production export တွင် မထည့်ထားပါ။
- Clean production export ကို Chromium 844×390 landscape touch emulation ဖြင့် menu, joystick လမ်းလျှောက်မှုနှင့် camera drag စမ်းသပ်ထားပြီး browser error မရှိပါ။
- Mesh-object budget regression တွင် ၄၈၂ node ရှိပြီး ၅၂၀ သတ်မှတ်ကန့်သတ်ချက်အတွင်းဖြစ်သည်။

**ကန့်သတ်ချက်။** စမ်းသပ်မှုအားလုံးသည် cloud Chromium/SwiftShader emulation သို့မဟုတ် Godot headless ဖြစ်ပြီး ရုပ်ပိုင်းဖုန်းပေါ်တွင် မစမ်းသပ်ရသေးပါ။ SwiftShader ၏ ၄-frame နမူနာတွင် frame interval ပျမ်းမျှ ၄၅၄ ms ခန့်သာ တိုင်းတာရသော်လည်း ၎င်းသည် အလွန်တိုပြီး software renderer ပေါ်မူတည်သည့် ရလဒ်ဖြစ်သောကြောင့် handset FPS ခန့်မှန်းချက်အဖြစ် မသုံးသင့်ပါ။ Android APK/AAB ကိုလည်း မထုတ်ရသေးပါ။

## ထိန်းချုပ်မှု

ဖုန်းတွင် ဘယ်ဘက် joystick ဖြင့် ရွေ့ပါ; ညာဘက်လွတ်နေရာကို ဆွဲ၍ ကင်မရာလှည့်ပါ။ အခြေအနေအလိုက် လုပ်ဆောင်ချက်ခလုတ်များ ပေါ်လာမည်။ ကွန်ပျူတာတွင် `WASD`/မြှားခလုတ်များဖြင့် ရွေ့၊ `Shift` ဖြင့်ပြေး၊ `E`/`Space` ဖြင့် လုပ်ဆောင်ပါ။

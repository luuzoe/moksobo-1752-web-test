# အလောင်းမင်းတရား — မုဆိုးဘို ၁၇၅၂ (Web Playtest)

[အခန်း ၁ Web preview ကိုဖွင့်ရန်](https://luuzoe.github.io/moksobo-1752-web-test/?build=phone-r7)။ ဤသည် ဆက်လက်စမ်းသပ်နေသော prototype ဖြစ်ပြီး အပြီးသတ်ဂိမ်း သို့မဟုတ် Android app မဟုတ်ပါ။

## phone-r7 ပြင်ဆင်ချက်

အခန်း ၁ ကို အစမှအဆုံးအထိ ကစားနိုင်သော mission loop အဖြစ် တိုးချဲ့ထားသည် — သတင်းပို့သူ၏ briefing၊ ပစ္စည်း ၃ မျိုးစုဆောင်းခြင်း၊ ပြန်လည်တည်ဆောက်ထားသော အမိန့်အစည်းအဝေးနှင့် ဂိတ်/ကင်းနေရာ ၃ ခု ပြင်ဆင်ခြင်းတို့ ပါဝင်သည်။ အခန်း ၁ ပြီးဆုံးလျှင် အခန်း ၂ ကို တိုးတက်မှုအဖြစ် ဖွင့်ပေးသော်လည်း ကစားနိုင်သောအကြောင်းအရာ မတည်ဆောက်ရသေးဟု ရှင်းလင်းစွာပြထားသည်။ မီနူးတွင် အခန်း ၁–၁၀ timeline ပါရှိပြီး၊ ပြီးစီးမှုမတိုင်မီ အခန်း ၂–၁၀ လော့ခ်ထားသည်။ ပြီးစီးပြီးနောက် အခန်း ၂ သာ progress-unlocked ဖြစ်ပြီး မတည်ဆောက်ရသေးသည့်အခြေအနေကို ဆက်ပြထားကာ အခန်း ၃–၁၀ လော့ခ်ထားသည်။

Joystick နှင့် camera ကို တစ်ပြိုင်နက်အသုံးပြုရာ spin ဖြစ်ခြင်း၊ အိမ်တိုက်မှုနှင့် ခြေထောက်မြေထဲဝင်ခြင်း၊ မြန်မာစာ UI အရွယ်အစားနှင့် ပြတ်သားမှုတို့ကို ပြင်ဆင်ထားသည်။ သမိုင်းမှတ်တမ်းအခြေခံအချက်များနှင့် ဂိမ်းအတွက် ပြန်လည်တည်ဆောက်ထားသော dialogue/mission အသေးစိတ်များကို သီးခြားတံဆိပ်တပ်ထားသည်။

## phone-r6 ပြင်ဆင်ချက်

Joystick ကိုဖိထားစဉ် player သည် camera ဦးတည်ချက်အသစ်ကို frame တိုင်းလိုက်မပြောင်းတော့ပါ။ လှုပ်ရှားမှုဦးတည်ချက်ကို ထိန်းထားပြီး လက်ချောင်းထိတွေ့မှု တစ်ခဏပြတ်သွားခြင်းကိုလည်း ၀.၁၂ စက္ကန့်အတွင်း ခံနိုင်အောင် ပြင်ထားသည်။ Camera swipe ကို frame တစ်ခုစီတွင် တစ်ကြိမ်သာယူပြီး turn rate ကိုကန့်သတ်ထားသဖြင့် browser က touch delta ကြီးတစ်ခုတည်း ပို့လာလျှင် မြင်ကွင်းတစ်ပတ်လုံး ချက်ချင်းလည်မသွားပါ။

အခန်း ၁ ပြီးဆုံးပြီးနောက် mission status သည် `✓ အခန်း ၁ ပြီးဆုံး` ဟုတိုတောင်းစွာပြပြီး မလိုအပ်တော့သော progress/health တန်းကိုဖျောက်ထားသည်။ Landscape ဖုန်းတွင် mission card နှင့် ဘယ်ဘက် joystick ပုံကိုလည်း လျှော့ထားသော်လည်း touch hit area ကိုအသုံးဝင်သည့်အရွယ်အစားတွင်ထားသည်။ မြန်မာစာကို font oversampling နှင့် outline ဖြင့်ပိုမိုရှင်းလင်းစေထားသည်။ မီနူး၊ အသုံးပြုသူသတ်မှတ်ထားသောရွာပုံ၊ save/continue၊ landscape layout၊ ညာဘက်ဝိုင်းပုံ action ခလုတ်များနှင့် တတိယပုဂ္ဂိုလ်မြင်ကွင်းကို ဆက်လက်ထိန်းသိမ်းထားသည်။

## စမ်းသပ်မှုရလဒ်

Gameplay controls, camera/multitouch, collision/grounding, menu/save, mobile UI, rendering နှင့် Chapter 1 flow အတွက် Godot source regression test ၁၁ ခုလုံး အောင်မြင်ခဲ့သည်။ ၈၄၄×၃၉၀ touch-enabled Chromium တွင် messenger interaction မှစ၍ ပစ္စည်း ၃ မျိုး၊ meeting၊ repair ၃ ခုနှင့် အခန်းပြီးဆုံးမှုအထိ browser touch route ကို စမ်းသပ်ခဲ့ပြီး၊ completion save ကို reload လုပ်ပြီး အခန်း ၂ unlock အဖြစ်ပြသမှုနှင့် Continue ပြန်ဖွင့်မှုကိုလည်း စစ်ဆေးခဲ့သည်။ Production Web export smoke test တွင် မီနူးနှင့် အခန်း ၁ အဖွင့်ပေါ်လာပြီး HTTP/JavaScript/runtime error မတွေ့ပါ။

ရုပ်ပိုင်းဆိုင်ရာဖုန်းပေါ်တွင် မစမ်းသပ်ရသေးပါ။ Browser test သည် phone-shaped Chromium touch simulation ဖြစ်ပြီး အမှန်တကယ်ဖုန်းစမ်းသပ်မှုဟု မဆိုလိုပါ။

## ကစားနည်း

ဖုန်းကို အလျားလိုက်ထားပြီး ဘယ်ဘက် joystick ဖြင့်ရွေ့ပါ။ ညာဘက်လွတ်နေရာကိုဆွဲ၍ camera လှည့်ပါ။ ကွန်ပျူတာတွင် `WASD` သို့မဟုတ် မြှားခလုတ်များဖြင့်လျှောက်ပါ၊ `Shift` ကိုဖိ၍ပြေးပါ၊ `E`/`Space` ဖြင့်လုပ်ဆောင်ပါ သို့မဟုတ် စကားဆက်ပါ၊ `Q` ဖြင့်ရှောင်ပါ၊ `B` ဖြင့်ကာကွယ်ပါ၊ `V` ဖြင့်လက်နက်ပြောင်းပါ။

## သမိုင်းနှင့် အခန်းအကျယ်အဝန်း

ဂိမ်းသည် အခန်း ၁ — ၁၇၅၂ ခုနှစ် မုဆိုးဘိုမှ ခုခံရေးကို အောင်ဇေယျ စုစည်းသည့်အပိုင်း — ကိုသာဖုံးလွှမ်းသည်။ အမည်မဖော်ထားသော စာပို့သူ၊ စကားဝိုင်း၊ ပစ္စည်းစုဆောင်းမှု၊ မစ်ရှင်အစီအစဉ်နှင့် ရွာပုံစံတို့သည် gameplay အတွက် ဖန်တီးထားသော ပြန်လည်တည်ဆောက်မှုဖြစ်ပြီး မှတ်တမ်းတင်ထားသော ကိုယ်ရေးဖြစ်ရပ်များဟု မဆိုလိုပါ။ မူရင်း Godot project နှင့် Android package ကို ဤ Web preview တွင် မထည့်ထားပါ။

## ပထမဆုံးဖွင့်ချိန်

WebAssembly (`.wasm`) ဖိုင်သည် ၃၉ MB ခန့်၊ game data (`.pck`) ဖိုင်သည် ၆၀ MB ခန့်ရှိသည်။ ပထမဆုံးဖွင့်ချိန်သည် ဖုန်းနှင့်ကွန်ရက်အမြန်နှုန်းပေါ်မူတည်၍ ကြာနိုင်သည်။ WebAssembly နှင့် WebGL 2 ကို ပံ့ပိုးသော ခေတ်မီ browser ကို အသုံးပြုပါ။

# အလောင်းမင်းတရား — မုဆိုးဘို ၁၇၅၂ (Web Playtest)

[အခန်း ၁ ကို browser ဖြင့်ကစားရန်](https://luuzoe.github.io/moksobo-1752-web-test/?build=phone-r5)။ ဤသည် ဆက်လက်ပြင်ဆင်စမ်းသပ်နေသော prototype ဖြစ်ပြီး အပြီးသတ်ဂိမ်း သို့မဟုတ် Android app မဟုတ်ပါ။

## phone-r5 ပြင်ဆင်ချက်

Startup မှာ Godot engine splash/logo ပုံကိုဖျောက်ပြီး `MOKSOBO 1752` loading label နှင့် မုဆိုးဘိုအခင်းအကျင်းပါ main menu ကိုပြထားသည်။ `Start` က Chapter 1 အသစ်စတင်ပြီး save ရှိပါက `Continue` က မူလတိုးတက်မှုကိုပြန်တင်သည်။ `Start` က save ဟောင်းကိုအစားထိုးမည့်အခါ သီးခြားအတည်ပြုချက်တောင်းပြီး အသစ်ကစားနေစဉ် autosave က save ဟောင်းကို မဖျက်ပါ။ Manual Save မှာလည်း overwrite အတည်ပြုချက်လိုသည်။

Chapter 1 ပြီးဆုံးသောအခါ mission card ကိုကျစ်လျစ်စေပြီး joystick ၏မြင်ရသည့်အရွယ်နှင့် လက်ထိန်းချုပ်ဧရိယာကို သီးခြားညှိထားသည်။ ကင်မရာကိုလှည့်ရင်း joystick ကိုဆက်ဖိထားလည်း ဇာတ်ကောင်၏ရွေ့လျားဦးတည်ချက် မလည်စေရန် ပြင်ဆင်ထားသည်။ ဤပြင်ဆင်မှုများကြောင့် လိုအပ်သောလိုင်စင် သို့မဟုတ် third-party notice များကို မဖယ်ရှားထားပါ။

## စမ်းသပ်မှုရလဒ်

Menu/save flow, camera orbit, responsive HUD, multitouch, mobile controls နှင့် Chapter 1 walkthrough အတွက် source regression suites ၆ ခု အောင်မြင်ခဲ့သည်။ Export လုပ်ထားသော Web build ကို touch-enabled mobile-browser emulation တွင် 844×390 နှင့် 1280×649 အရွယ်အစားများ၌ စတင်ဖွင့်ခြင်း၊ `Start` နှိပ်ခြင်း၊ Chapter 1 ထဲဝင်ခြင်း၊ joystick ဖြင့်ရွေ့ရင်း ကင်မရာဆွဲခြင်းတို့ စမ်းသပ်ခဲ့ပြီး JavaScript/runtime error နှင့် မအောင်မြင်သည့် asset request မရှိပါ။ ရုပ်ပိုင်းဆိုင်ရာဖုန်းစက်ပေါ်တွင် မစမ်းသပ်ရသေးပါ။

## ကစားနည်း

ဖုန်းကို အလျားလိုက်ထားပြီး ဘယ်ဘက် joystick ဖြင့်ရွေ့ပါ။ ညာဘက်လွတ်နေရာကို ဆွဲ၍ ကင်မရာလှည့်ပါ။ ကွန်ပျူတာတွင် `WASD` သို့မဟုတ် မြှားခလုတ်များဖြင့်လျှောက်ပါ၊ `Shift` ကိုဖိ၍ပြေးပါ၊ `E`/`Space` ဖြင့်လုပ်ဆောင်ပါ သို့မဟုတ် စကားဆက်ပါ၊ `Q` ဖြင့်ရှောင်ပါ၊ `B` ဖြင့်ကာကွယ်ပါ၊ `V` ဖြင့်လက်နက်ပြောင်းပါ။

## သမိုင်းနှင့်အခန်းအကျယ်အဝန်း

ဂိမ်းသည် အခန်း ၁ — ၁၇၅၂ ခုနှစ် မုဆိုးဘိုမှ ခုခံရေးကို အောင်ဇေယျ စုစည်းသည့်အပိုင်း — ကိုသာ ဖုံးလွှမ်းသည်။ အမည်မဖော်ထားသော စာပို့သူ၊ စကားဝိုင်း၊ ပစ္စည်းစုဆောင်းမှု၊ မစ်ရှင်အစီအစဉ်နှင့် ရွာပုံစံတို့သည် gameplay အတွက် ဖန်တီးထားသော ပြန်လည်တည်ဆောက်မှုဖြစ်ပြီး မှတ်တမ်းတင်ထားသော ကိုယ်ရေးဖြစ်ရပ်များဟု မဆိုလိုပါ။ မူရင်း Godot project နှင့် Android package ကို ဤ Web preview တွင် မထည့်ထားပါ။

## ပထမဆုံးဖွင့်ချိန်

WebAssembly (`.wasm`) ဖိုင်သည် 39.5 MB ခန့်၊ game data (`.pck`) ဖိုင်သည် 60 MB ခန့်ရှိသည်။ ပထမဆုံးဖွင့်ချိန်သည် ဖုန်းနှင့်ကွန်ရက်အမြန်နှုန်းပေါ်မူတည်၍ ကြာနိုင်သည်။ WebAssembly နှင့် WebGL 2 ကို ပံ့ပိုးသော ခေတ်မီ browser ကို အသုံးပြုပါ။
